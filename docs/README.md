## Start from a task

- Deploy a real team gateway with the [complete VPS tutorial](teams.md).
- Find the login commands in [provider accounts](02-provider-accounts/README.md).
- Connect a laptop through [developer setup](03-developer-setup/README.md).
- Explore the [dashboard screenshots](04-dashboard/README.md).
- Read [CONTRIBUTING.md](../CONTRIBUTING.md) before opening a pull request.

Dashboard account onboarding is tracked in [issue #3](https://github.com/sep1ol/relaycrew/issues/3). Provider sign-in currently runs through the CLI. The screenshot tour uses the isolated local preview and synthetic data.
